# AI-Powered Git Tool (aigit)

## Overview
`aigit` is an AI-powered Git tool that allows users to execute Git commands using natural language. It translates user input into actual Git commands and executes them.

## Installation
1. Run the installer and follow the on-screen instructions.
2. Ensure `aigit` is added to your system PATH for easy access.

## Usage
Open Git Bash or Command Prompt and run:
```
aigit "commit my changes"
```
This will automatically translate and execute the correct Git command.
